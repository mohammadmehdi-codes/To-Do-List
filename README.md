# To-Do List 📝

A simple To-Do List program made with Python.

## What it can do

- Add tasks
- View tasks
- Delete tasks
- Mark tasks as completed
- Save tasks so they don't disappear when you close the program
- Handle invalid input

## How to use

Run the Python file and choose an option from the menu:

1. Add task
2. View task
3. Delete task
4. Mark task as complete
5. Exit

Tasks are saved in a JSON file and loaded again when you start the program.

## Built with

- Python
- JSON
